# Claude Code

Read [AGENTS.md](AGENTS.md) before working in this repository. It is the shared
source for architecture, branch/worktree ownership, ticket checklists, safety,
verification, GoF review and agent-document writing rules.

Use an owned `claude/<topic>` branch and dedicated worktree. Read
[mastering operations](docs/agents/mastering-operations.md) for the active
Company, Person and Relationship scope and local qualification command.

Consult available skills when their instructions help the requested task.
Preserve exact operator approvals and verify current state from code and live
evidence. Historical memory and handoff notes are context, not execution proof.
