## Question

What recovery owner, resume procedure and measured maximum make it safe to
enable the new versioned quality receipt format?

## Checklist

- [ ] Document the resume procedure for an interrupted run using the new format.
- [ ] Measure a disposable resume without using provider data.
- [ ] Have the operator set the maximum recovery time after reviewing the
  measurement.
- [ ] Keep the feature disabled unless the measured resume completes within the
  maximum; record the evidence before enablement.
