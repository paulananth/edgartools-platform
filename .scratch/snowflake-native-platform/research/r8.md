- 5 need a profile line or a guard: load.sh:87, load_jobs.py:251-272 and 1545, 302-304/803-816/1612, monitoring.py (R7).

## Smallest seam for one image and one rules folder

1. One orchestrator adapter with poll, heartbeat, report and start-lanes. The JSON task protocol in activity_worker.py's docstring stays the contract. Changes: load.sh, compose.yml, activity_worker.py:136-141.
2. Configuration by env, already in place: DATA_URL, CONTROL_URL, STORES, CAPTURES, PROVING, LOGS, EDGAR_WAREHOUSE, CAPACITY. Snowflake sets them; the image and rules folder do not change.
3. Engine and readiness stop calling the platform: CI evidence as a file, state files instead of `ps`, a stage branch for captures. Then one image runs everywhere.

The rules folder is not platform-neutral today: rules/load-jobs.yaml:23-27 names AWS task sizes. A Snowflake pool is one more line there, not a code change.
