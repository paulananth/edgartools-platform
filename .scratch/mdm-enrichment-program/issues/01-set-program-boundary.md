# Set the MDM Enrichment Program boundary

Type: grilling
Status: resolved

## Question

Should one plan cover shared GLEIF evidence, all identified domain consumers,
production operation, and adjacent non-GLEIF enrichment without implementing
unsafe identity or relationship interpretations?

## Answer

Yes. The program includes all identified GLEIF evidence families, mappings,
domain consumers, production concerns, and separately governed non-GLEIF source
decisions. Replacing CIK, name-only automatic merging, cross-domain coercion,
and treating accounting consolidation as ownership are prohibited acceptance
boundaries, not planned capabilities.
