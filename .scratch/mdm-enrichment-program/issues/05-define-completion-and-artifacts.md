# Define completion and planning artifacts

Type: grilling
Status: resolved
Blocked by: 04

## Question

When are planning and delivery complete, how do conditional sources terminate,
and which artifacts carry the program forward?

## Answer

Planning completes when every workstream has a destination, dependencies,
authority, evidence, gates, owner, and terminal outcome path. Delivery completes
when mandatory consumers have production evidence and every conditional source
has shipped or reached an evidenced defer/reject outcome with an objective
review trigger. Conditional research must decide `adopt`, `defer`, or `reject`
after authority, license, coverage, value, identity safety, cadence, cost,
replay, retention, and ownership review. The program uses a parent map,
dependency plan, workstream charters, specification index, focused ADR, corrected
Company child map, and shared glossary. Executable tickets wait for a verified
consumer specification.
