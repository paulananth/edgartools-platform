# Choose the program and release structure

Type: grilling
Status: resolved
Blocked by: 01

## Question

How should the comprehensive scope be organized, sequenced, released, and
classified without creating one big-bang implementation?

## Answer

Use a parent MDM Enrichment Program above the existing Company evidence map.
Build the shared foundation first; release Company next; then run Security,
Branch, and Fund consumers independently and in parallel where edit ownership
allows. Remaining explicit domains follow. Open GLEIF sources are mandatory
when their owning domain exists; licensed and non-GLEIF sources are conditional;
unsafe semantic interpretations are prohibited. Every consumer owns independent
tests, checkpoints, rollback, observability, and release approval.
