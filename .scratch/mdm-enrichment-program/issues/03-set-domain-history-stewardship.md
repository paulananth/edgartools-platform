# Set domain, history, and stewardship boundaries

Type: grilling
Status: resolved
Blocked by: 02

## Question

How should unsupported GLEIF entity categories, historical evidence, review
decisions, and the existing 308-link Company cohort be represented?

## Answer

Add explicit domains when their consumers are specified; never manufacture a
Company or generic entity from an LEI. Unsupported evidence remains captured
and nonpublishing. Begin with a verified current Golden Copy baseline, retain
immutable forward deltas, and treat historical reconstruction as a separately
verified backfill. Use distinct identity-link, field-conflict,
relationship-endpoint, and identifier-mapping reviews whose decisions retain
source and run evidence and never imply an entity merge. Import the 308 links as
adjudicated seed evidence and revalidate each before publication.
