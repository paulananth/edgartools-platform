# Recompute incorrect merges from retained evidence

Accepted on 2026-09-18 in the [Clean MDM policy interview](../../.scratch/clean-mdm/issues/01-set-merge-stage-policy.md), Q7: reverse an incorrect merge by recomputing affected identities and relationships from retained evidence, preserving valid later corrections and sending uncertain ownership to review. A scoped Match Exclusion prevents automatic recurrence until an evidence-bound decision revokes it, and reversal completes only after downstream changes are verified. This requires retaining source attribution and decision history instead of restoring an old snapshot that could discard later corrections; detailed dependency handling and ID restoration rules remain open.
