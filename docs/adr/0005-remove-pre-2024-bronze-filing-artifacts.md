# Remove pre-2024 bronze filing artifacts after manifest review

The completed production historical-bronze review found 212,444 current filing-object versions totaling 22.275 GiB with accession years from 2000 through 2023. The Release Owner approved their removal after the complete exact-VersionId manifest was validated against the active account and no overlap was found with the current release-evidence accession set; release evidence and every non-filing bronze prefix remain outside this deletion scope.
