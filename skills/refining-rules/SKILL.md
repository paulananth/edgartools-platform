# Refining Rules

Refining rules is part of [MDM Engineering](../mdm-engineering/SKILL.md#refining-rules).
Read and follow its [Refining rules procedure](../mdm-engineering/REFINING-RULES.md)
for every refinement task. That document owns the modes, measurement, checks,
approval and activation handoffs; this entry point preserves existing links
and skill invocations without keeping a second procedure.
